# 歌詞動画 透過合成（VideoEditing）

歌詞動画の背景を抜いて、文字と効果だけを好きな背景（画像・動画）に重ねるアプリです。

## Web 版

ブラウザ（Google Chrome・Microsoft Edge）で動きます。動画の読み込み・合成・書き出しは、すべてパソコンのブラウザの中で行い、ファイルがどこかへ送られることはありません。

- アプリ：GitHub Pages で公開したページの `web/` を開いてください
- ソースと使い方：[web/](web/)（使い方はアプリ内の「？ ヘルプ」）

## Windows 版

準備中です。
