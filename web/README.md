# 歌詞動画 透過合成（Web 版）

歌詞動画の背景を抜いて、文字と効果だけを別の背景（画像・動画）に重ねるアプリの Web 版です。
Windows 版（VideoEditing）と同じ計算で合成します。

動画の読み込み・合成・書き出しは、**すべてパソコンのブラウザの中で行います**。ファイルがどこかへ送られることはありません。

## 使い方

1. `index.html` を **Google Chrome** か **Microsoft Edge** で開きます（ダブルクリックで開けます）。
2. ① 歌詞動画、② 背景（画像または動画）を選びます。枠にドラッグ＆ドロップでも登録できます。
3. ③ 調整で、背景の抜き具合・縁取り・粒ノイズ・縁取りの色を決めます。プレビューにすぐ反映されます。
4. ④ 書き出しの「書き出し開始」を押すと MP4 を書き出します。「歌詞動画と同じフォルダーに保存する」がオンなら、歌詞動画の隣に直接書き出します（フォルダーごとに最初の 1 回だけ、フォルダーの確認と書き込みの許可があります）。

詳しい使い方（区間ごとの調整のしかたなど）は、アプリの <b>？ ヘルプ</b> ボタン（または F1 キー）で開く `help.html` を見てください。

### 操作

| 操作 | 内容 |
|---|---|
| ← / → | 1 コマ戻る / 進む（押し続けると連続） |
| Shift＋← / → | 1 秒戻る / 進む |
| スペース | 再生 / 停止 |
| F11、プレビューをダブルクリック | 全画面（Esc で戻る） |
| F1 | ヘルプを開く |

### 区間ごとの設定

「◆ ここから」「ここまで ◆」で範囲を決めて「＋ 区間を追加」を押すと、その範囲だけ別の調整値を使えます。
赤い区間はダブルクリックで設定、右クリックでメニューが出ます。区間の境目では 0.25 秒かけてなめらかに切り替わります。

区間ファイル（JSON）は **Windows 版と同じ形式** なので、どちらで保存したものも読み込めます。
区間を保存すると、保存の画面は歌詞動画のフォルダーで開き、歌詞動画・背景の場所もブラウザの中に覚えておきます。
区間ファイルを読み込むと、歌詞動画・背景も自動でセットされます（ファイルが変わっていたり、見つからなかったりしたときは確認が出ます）。

## Windows 版との違い

- FFmpeg は要りません（ブラウザの動画機能 WebCodecs を使います）。
- 書き出しの画質は、Windows 版の CRF ではなくビットレートで決めます（「最高画質」「高画質」「標準」）。
- ブラウザではファイルの場所（フルパス）が分からないため、区間ファイルにはファイル名だけを保存します。場所はブラウザの中（IndexedDB）に覚えておき、区間ファイルの `WebFileId` と結びつけます（Windows 版はこの項目を読み飛ばします）。
- 設定・基準値は、このブラウザの中に保存されます。

## 動作環境

- Google Chrome / Microsoft Edge（パソコン版の最新版）
- 歌詞動画・背景動画は MP4（H.264 など）を想定しています。
